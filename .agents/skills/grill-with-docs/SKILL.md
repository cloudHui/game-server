# Grill-With-Docs 文档对齐与质询技能

## 何时使用
- 方案涉及前端 Vue3 迁移或与老 Web 页面交互；
- 方案涉及 Hub 与旧五服务（center/gate/lobby/game/web）的边界划分；
- 用户的术语与现有代码或规范产生歧义时。

## 执行流程
1. **现有文档自检**：
   - 查阅 `AGENTS.md`、`readme.md`、`vue3-migration-plan.md` 及相关规则；
   - 提取领域统一语言（例如：区分“桌子 Table”与“房间 Room”、“用户 User”与“角色 Role”）。
2. **术语与决策挑战**：
   - 当用户使用的表述与系统既定术语冲突时，当场明确指出并澄清；
   - 当方案违背已有架构决策（例如试图直接在 Hub 外部开启多个互相通信的独立进程，违背了 Hub 单进程主线原则）时，提出预警。
3. **单步逐问并记录决策**：
   - 参照 `grill-me` 模式，每次只抛出一个关键质询并带推荐；
4. **结晶沉淀回文档**：
   - 讨论结束后，主动提示用户并将确定的决策以补丁形式更新到相应的说明文档或 `AGENTS.md` 中。
