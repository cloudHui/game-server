# Handoff 会话交接技能

将当前长会话的进展、已达成共识、未决事项与环境状态进行压缩提炼，生成交接文档，确保新 Agent 能够零摩擦直接上手。

## 何时使用
- 当前上下文长度过长，需要清理上下文开启新会话继续开发；
- 某个复杂功能排查告一段落，需要换一个模式或不同模型承接下一步任务；
- 用户明确提出“写个交接文档”、“保存交接记录”。

## 文档输出结构

1. **目标与背景（Objective & Scope）**：
   - 当前正在推进的核心需求或 Bug 描述。
2. **已完成工作与改动资产（Completed Work & Modified Assets）**：
   - 已修改的文件清单及改动简述（附带代码路径链接）；
   - 验证结论（测试通过/编译成功等证据）。
3. **关键决策与共识（Key Decisions）**：
   - 为什么采取当前的方案（架构、选型、红线约束）。
4. **下一步行动清单（Next Steps & Recommendations）**：
   - 接下来需要哪个文件动工；
   - 推荐新 Agent 激活的技能（如 `@msg-handler`, `@code-review`, `@canvas`）。
5. **未决问题与风险提示（Open Issues & Risks）**：
   - 遗留的隐患或等待人工确认的事项。

## 规范要求
- 敏感信息脱敏：严禁包含数据库真实密码、Token 或私密凭据；
- 链接化：所有关键类名与文件使用清晰的路径链接，方便直接跳转。
