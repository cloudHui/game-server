# MCP-Log-Copylog 日志安全切片与取证技能

## 何时使用
- 玩家报错偶现，但日志体量过大难以直接通读；
- 需要截取特定日期区间（如昨天到今天）的日志切片；
- 需要按指定关键词（如特定 `userId` 或异常类名）过滤日志命中行。

## 机制与执行规范
1. **源日志只读**：
   - copylog 工具仅对目标日志进行只读流式扫描与复制，绝对不篡改任何源日志文件；
2. **过滤模式**：
   - 空条件复制完整时间段日志；
   - 指定条件时自动调用高效文本匹配（如 `rg` 或 `grep`），只保留命中上下文行；
3. **输出落地**：
   - 切片结果统一输出在当前环境的 `log/logs_起日_止日/` 目录中，便于进一步精确定位；
4. **证据闭环**：
   - 提取出具体异常堆栈与关键时间节点后，对照源码出具诊断报告。
