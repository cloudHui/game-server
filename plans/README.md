# 项目计划归档目录 (plans/)

本目录用于存放 `game-server` 项目的所有架构重构、功能迭代与阶段性实施计划。

## 计划文档维护规范
1. **命名规范**：采用英文中划线命名，如 `message-refactor-and-hub-sync-plan.md`。
2. **任务追踪格式**：
   - `- [ ]` 未开始
   - `- [/]` 进行中
   - `- [x]` 已完成
3. **闭环原则**：每个阶段任务完成后，立即在对应的 plan 文档中更新为 `[x]`，确保研发进度可实时审计，杜绝半途而废。
